# notas/ — Apuntes de trabajo

Material en crudo: lo que sale de una conversación, de una sesión de trabajo o de
una idea a medio cocer. **Se permite que esté desordenado.** Es mejor un apunte
feo escrito que uno bonito que nunca se escribió.

## Qué va aquí
- Conclusiones sacadas de una conversación con Claude
- Apuntes de una llamada o reunión
- Ideas sueltas, hipótesis, cosas por explorar
- Resultados de un experimento o prueba
- Listas de dudas pendientes

## Cómo se relaciona con las otras carpetas
```
notas/  →  cuando algo se consolida y se cierra  →  decisiones/
notas/  →  cuando algo se consolida como referencia estable  →  context/
```
Las notas son el borrador. Lo que sobrevive, se promueve.

## Nombre de archivo

```
AAAA-MM-DD-tema.md
```

Ejemplos:
```
2026-09-29-lluvia-de-ideas-nichos.md
2026-10-02-llamada-con-posible-cliente.md
```

## Plantilla mínima

```markdown
# [Tema]

_2026-09-29 · [quién lo escribe]_

## Qué salió
- ...

## Dudas abiertas
- ...

## Siguiente paso
- ...
```

## Aviso
Para Claude, `notas/` es **borrador, no verdad establecida**. Si una nota contradice
una decisión de `decisiones/`, manda la decisión.
